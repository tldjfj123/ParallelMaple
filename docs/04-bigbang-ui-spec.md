# 빅뱅(Big Bang) 스타일 UI 화면별 설계서

> 웹 리서치 + MSW 공식 `StatusBar2` / `UIWindow2` / `QuickSlot` 에셋 조사 결과를 바탕으로,  
> "웹 대시보드 느낌"을 빼고 **진짜 2010년 빅뱅 메이플스토리 감성**을 구현하기 위한 화면별 UI 명세입니다.

---

## 왜 기존 UI가 메이플과 다르게 보였나? (핵심 원인 3가지)
1. **단색 사각형 패널 사용:** MSW 안에 실제 메이플 공식 `StatusBar2` / `UIWindow2` / `QuickSlot` 스프라이트가 있는데 단색 박스를 써서 이질감이 큼
2. **과도하게 큰 하단바 + 글씨 퀵슬롯:** 빅뱅 하단바는 컴팩트하고(높이 70~80px급), 퀵슬롯은 긴 텍스트 버튼이 아니라 **정사각형 칸(`48×48`) 안에 스킬/아이템 아이콘 + 좌상단 작은 키캡(`1`, `2`, `Z`)** 구조
3. **창 구조:** 모든 걸 한 거대한 모달에 몰아넣기보다, 빅뱅 특유의 **컴팩트한 개별 팝업 창** (`E` 장비 / `I` 인벤토리 / `S` 스탯 / `K` 스킬 / 장비 강화창) + 하단 아이콘 메뉴 구성이 원작 감성을 살림

---

## 화면별 상세 UI 계획 (6개 화면 순차 적용)

### 화면 1. 메인 인게임 HUD (가장 먼저 개편!)
- **① 하단 상태바 (`StatusBar2` 공식 스프라이트 기반):**
  - 좌측: **Lv. 숫자** (노란 굵은 숫자) + 직업/닉네임
  - 중앙: 공식 게이지 스프라이트 기반 **빨간 HP 바** / **파란 MP 바** + 하단 **노랑-연두 10칸 EXP 바**
  - 메뉴 아이콘 열: **`E` 장비** · **`I` 인벤** · **`S` 스탯** · **`K` 스킬** · **`U` 강화** · **`F` 자동** · **`M` 맵** (컴팩트 아이콘/버튼)
- **② 우측 하단 정사각형 퀵슬롯 (`QuickSlot` 2줄 × 4~6칸):**
  - 각 칸은 **정사각형 슬롯** + 실제 **메이플 스킬/아이템 아이콘 스프라이트** + 좌상단 노란 단축키(`1`, `2`, `Z`, `F`, `U`, `J`, `M`)
- **③ 상단 미니맵 (반투명 다크 네이비 + 실버 프레임):**
  - 지역명/맵명 + 채널 + 노란 플레이어 점 + 접기/펼치기(`+/-`) 버튼
- **④ 좌측 하단 채팅/시스템 로그창:**
  - MSW 기본 `UIChat`과 겹치지 않게 위치 정돈, 획득 로그(메소/주문서/큐브/장비) 자연스럽게 표시

### 화면 2. 장비창 (`E`) — 빅뱅 마네킹 슬롯 스타일
- 밝은 회색/실버 메탈릭 `UIWindow2` 프레임 + 파란 상단 타이틀바 (`EQUIPMENT`)
- 중앙에 장착 **8부위 슬롯**을 원작 배치대로 사각형 아이콘 칸으로 배열 (`모자` / `무기` / `보조` / `엠블렘` / `상의` / `장갑` / `신발` / `반지`)
- 잠재능력 등급별 **테두리 컬러** (레어 파랑 / 에픽 보라 / 유니크 노랑 / 레전드리 초록) + 별(`★`) 표시

### 화면 3. 인벤토리 창 (`I`) — 빅뱅 4탭 가방 스타일
- 상단 탭: **`[장비]`** / **`[소비(큐브/주문서)]`** / **`[기타(주문의 흔적)]`**
- 4열 정사각형 아이템 아이콘 그리드 + 하단 **보유 메소 표시** (`메소 동전 아이콘 + 숫자`)
- 장비 클릭 시 장착/강화 바로 연결, 파괴된 **장비의 흔적**은 반투명 붉은 테두리로 표시

### 화면 4. 스탯창 (`S`) & 스킬창 (`K`)
- **스탯창 (`S`):** 캐릭터 이름, 직업(전직 전환 버튼), 레벨, **전투력(스공)**, 주스탯, 공격력, 크확/크뎀, 보공, 방무, 메획/드랍률 깔끔한 2열 테이블
- **스킬창 (`K`):** 1차 탭에 현재 직업의 1차 스킬 2종 아이콘 + 데미지 배율/타수/쿨타임 설명 + `[시전]`/`[직업 변경]`

### 화면 5. 장비 강화 창 (`U` — 주문의 흔적 / 스타포스)
- 원작 **장비 강화 팝업** 스타일 (컴팩트 중앙 팝업):
  - 상단 장비 아이콘 슬롯 + 상단 **별(★☆☆☆☆)** 5개씩 끊어 표시 (최대 25성)
  - 탭 1 **[주문의 흔적]:** 100/70/30/15% + 순백/이노센트/황망 + 연속작
  - 탭 2 **[스타포스]:** 현재성→다음성 스탯 증가 미리보기, 확률, 비용, 파괴방지 체크박스, 찬스타임 배너, 파괴 시 스페어 전승 복구

### 화면 6. 잠재능력 큐브 창 (블랙 큐브 `BEFORE / AFTER` 전용 팝업)
- 원작 큐브 창 스타일의 세로형 컴팩트 팝업:
  - 상단: 장비 아이콘 + 현재 등급 배지(파랑/보라/노랑/초록) + 천장 카운트
  - 중단: **BEFORE 박스** vs **AFTER 박스** (블랙 큐브 사용 시 상하/좌우 비교 강조)
  - 하단: 큐브 선택 + `[한 번 더 사용하기]` / `[BEFORE 유지]` / `[AFTER 적용]`

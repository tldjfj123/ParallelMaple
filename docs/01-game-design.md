# ParallelMaple 정식 게임 기획서 (v2.0)

> **프로젝트명:** ParallelMaple (패러렐메이플)  
> **플랫폼:** MapleStory Worlds (MSW — 그룹 월드: `패러렐메이플`)  
> **장르:** 빅뱅 감성 정통 방치형 RPG & 강화 도파민 시뮬레이터  
> **한 줄 컨셉:** **"빅뱅 이후, 내 일상과 평행하게 돌아가는 방치형 메이플 — 본메에선 돈 수백만 원 깨지던 큐브·스타포스·놀긍혼·놀장강 도파민 파티를 무료 파밍만으로!"**

---

## 0. 월드 컨셉 & 정체성 (Why ParallelMaple?)

### 0.1 이름의 의미 — `ParallelMaple`
- **내 일상과 평행(Parallel)하게 돌아가는 메이플**: 일하거나 공부하는 동안에도 공용 사냥터에서 3펫 자석펫과 함께 사냥이 돌아가고, 꺼두어도 최대 12시간 오프라인 보상이 쌓이는 부담 없는 방치형 메이플.
- **과금 장벽 없는 평행세계(IF) 메이플**: 원작에서 현금 수십~수백만 원이 필요해 구경만 해야 했던 **레전드리 큐브 3줄 · 22성 스타포스 · 놀긍혼 리턴작 · 놀장강** 같은 메이플 최고의 도파민 강화 경험을 **100% 인게임 사냥·보스 파밍만으로 마음껏 즐길 수 있는 세계**.

### 0.2 시대 감성 & 비주얼 톤
- **외형 & 향수 = 2010 빅뱅(Big Bang) 황금기**: `StatusBar2`/`UIWindow2`/정사각형 퀵슬롯, 추억의 빅뱅 사냥터 18곳(헤네시스~황혼의 페리온), 바닥 포물선 드랍 + 3펫 자석펫, 클래식 레벨업 황금 빛기둥 & 종별 몬스터 SFX.
- **성장 & 재미 = 메이플 역대 최고 도파민 콘텐츠 집약**: 주문의 흔적 + 특수 주문서(놀긍혼/놀장강 확장) + KMS 스타포스 + 큐브 천장 & 블랙큐브 선택 + 1인 보스전(자쿰~루시드) + 세트 장비(카루타/앱솔/아케인).

### 0.3 타겟 유저 & 핵심 재미
- **타겟**: 빅뱅 시절 메이플의 추억은 있지만 본메의 과금·일퀘 피로도는 부담스러운 유저, 강화 도파민과 숫자 성장 쾌감을 좋아하는 방치형 RPG 유저.
- **차별화 포인트** *(개발·테스트하면서 지속 발굴 및 보강)*:
  - 단순 텍스트/클리커 방치가 아닌 **실제 공용 메이플 맵 + 공식 아바타·스킬·드랍 연출** 위에서 돌아가는 진짜 메이플 방치 경험
  - 과금 없이도 끝없이 질러볼 수 있는 **무료 강화 도파민 파티** (주문서·놀긍혼·스타포스·놀장강·큐브)

## 1. 확정된 핵심 방향성 (v1.0 Scope)

| 영역 | v1.0 확정 설계 | 비고 / v1.1+ 확장 |
| :--- | :--- | :--- |
| **직업 & 만렙** | **전사(히어로 계보) 단일 직업** (0차 초보자 → 1차 검사 → 2차 파이터 → 3차 크루세이더 → 4차 히어로), **최대 Lv.200** | 추후 4직업군(법/궁/도), 5차 전직 확장 여지 확보 |
| **성장 템포** | **정통 KMS 1배 점진 성장** — Lv.1 초보자 장비 시작, **장비 착용 레벨(`reqLevel`) 강제**, 본메 고증 보조무기(30/60/100)·엠블렘(60/100) 단계 지급 | 기존 테스트용 Lv.140 초기 지급 제거 |
| **전투 방식** | 실제 메이플 공용 사냥터 **자동사냥 + 수동 조작 병행** (수동 입력 시 2초 유예) + **3펫 자석펫 기본 지원** | 타격 기여 전원 개인 보상 (드랍 쟁탈 없음) |
| **피격 & 생존** | **HP 50% 이하 자동 포션 사용** + 일반 사냥터 사망 시 헤네시스 부활(**경험치 패널티 없음**) | 보스전은 데스카운트 5회 + 제한시간 10분 |
| **장비 슬롯** | **핵심 8부위 확정** (`무기 / 보조무기 / 엠블렘 / 모자 / 상의 / 신발 / 장갑 / 반지`) + **2/4/6 세트 효과** | `equipped[slotId]` 구조로 추후 14~16부위 확장 |
| **장비 수급 분리** | **일반 사냥터(18개)**: Lv.1~140 펜살리르까지 드랍 / **1인 보스전(5단계) & 보스 코인 상점**: 카루타·앱솔·아케인 전용 수급 | 스페어 수급도 보스 드랍 + 코인 상점으로 순환 |
| **3대 강화** | **주문의 흔적**(쾌적 비용 15~100, 연속작, 순백/이노/황망) + **스타포스**(KMS 0~25성, 15~16성 파방, 찬스타임, 흔적/스페어 12성 복구, 스타캐치 간편 토글) + **윗잠재 큐브**(5종, 천장, 블랙큐브 선택) | **놀긍혼(리턴)·놀장강(12성 파란별)** · 에디셔널 잠재는 v1.1+ 확장 |
| **경제 & 편의** | **장비 개별/일괄 판매·분해(잠금 보호)** + **NPC 상점**(포션/주흔/큐브/보스 코인 교환) | BM(유료 상품)은 v1.0 미포함 |
| **방치 리텐션** | **오프라인 방치 보상** (`DateTime.UtcNow` 기준 최대 12시간, 마지막 사냥터 80% 효율 정산) | 랭킹 보드 & 장비 도감 UI는 v1.1+ |

## 2. 코어 게임 루프 (Core Loop)

```text
[1. 공용 사냥터 방치 / 수동 사냥 (Lv.1 ~ Lv.200, 18개 사냥터)]
   - 3펫 자석펫 자동 루팅, 타격 기여자 전원 개인별 EXP/메소/전리품/포션/주흔/큐브/장비 획득
   - HP 50% 이하 시 자동 포션 소모 / Lv.100+ 스타포스 사냥터(30/55/80/140★) 공략
   - 접속 종료 시 최대 12시간 오프라인 방치 보상 누적
        │
        ▼
[2. 마을(헤네시스) 정비 · 상점 · 인벤토리 정리]
   - 전리품 판매 / 불필요 장비 일괄 분해(주흔) 또는 판매(메소)
   - NPC 상점에서 포션·큐브 보충
        │
        ▼
[3. 3대 강화 & 세트 업그레이드]
   ① 주문서 작(100/70/30/15%, 순백/이노/황망) → 업횟 0 해금
   ② 스타포스(0~25성, 파괴방지, 찬스타임, 파괴 시 스페어 12성 전승 복구)
   ③ 윗잠재 큐브(레어→에픽→유니크→레전드리, 천장 & 블랙큐브 선택)
   ④ 2/4/6 세트 효과 활성화 → 전투력 급상승
        │
        ▼
[4. 전직 돌파 & 1인 보스전 5단계 도전]
   - Lv.10 검사 → Lv.30 파이터 → Lv.60 크루세이더 → Lv.100 히어로 전직
   - 자쿰(50) → 혼테일(120) → 카오스 루타비스(150) → 스우(160) → 루시드(200)
   - 보스 드랍 & 보스 코인 상점으로 카루타/앱솔랩스/아케인셰이드 장비 및 스페어 획득
        │
        └──────────────────────────────▶ (반복)
```

## 4. 현재 구현 현황 (As-Is) vs 앞으로 구현할 항목 (To-Be)

### 구현 완료 (As-Is — 현재 `workspaces/ParallelMaple`에 동작 중)
- **맵/스폰**: 헤네시스 마을 + 사냥터 18개, 공식 발판 앵커 몹 밀집 스폰(38~46마리), 종별 공식 SFX
- **히어로 0~4차**: 전직(`J`), 액티브 7종 + 패시브 5종, 콤보 카운터(최대 10스택), 레벨업 빛기둥/충격파
- **자동사냥 & 드랍**: `F` 자동사냥, 타격 기여 개인 보상, 바닥 포물선 드랍, 3펫 자석펫(`P`), 무기 외형 반영
- **3대 강화 서버/UI**: 주문서(100/70/30/15%, 연속작, 순백/이노/황망), 스타포스(0~25성, 파방, 찬스타임, 흔적/스페어 복구), 큐브(5종, 천장, 블랙큐브 Before/After)
- **스타포스 사냥터 보정**: 4곳(30/55/80/140★) 데미지/추경 보정
- **기본 UI 6창 & 저장**: 빅뱅 HUD + `E/I/S/K/M/U` 창, `DataStorageService` 저장(`idle_save_v1`)

3. **장비 세트 효과 (2/4/6세트)**: `RecalculateStats`에 세트 효과 합산 + UI 툴팁/스탯 표시

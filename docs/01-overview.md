# 메이플스토리 방치형 키우기 기획서 (v1.0 — 확정)

> **프로젝트명 (가칭):** Jerry Maple Idle  
> **플랫폼:** MapleStory Worlds (MSW)  
> **장르:** 메이플스토리 정통 감성 방치형 RPG (Idle RPG)  
> **핵심 차별점:** 실제 메이플 공용 필드 자동사냥 + 원작의 **주문서 작 / 스타포스 / 잠재능력(큐브)** 3대 강화 시스템

---

## 1. 확정된 핵심 설계 요약

| 영역 | 확정 설계 |
| :--- | :--- |
| **전투/방치 방식** | 실제 메이플 맵 **필드 자동사냥 + 수동 조작 병행** (직접 이동/공격 시 즉시 수동 전환, 2초 무입력 시 자동사냥 복귀) |
| **직업 및 스탯** | **단일 모험가 통합 스탯** (주스탯 1종 + 공격력 기반) — 추후 4직업군 확장 가능 구조 |
| **스킬/전직** | **1차 → 2차 → 3차 → 4차** 레벨 달성 시 주력기·광역기·버프 자동 해금, 자동사냥 중 쿨타임마다 자동 시전 |
| **채널/인스턴스** | **마을(헤네시스) & 사냥터 모두 공용 채널** (옛날 메이플 감성) + **보스전만 1인 개인 인스턴스** |
| **공용 사냥터 분배** | **개인 드랍 + 빠른 리젠 + 타격 기여 보상** (1대 이상 타격 시 참여자 전원 개인별 경험치·메소·드랍 획득) |
| **장비 슬롯** | **핵심 8부위** (무기/보조무기/엠블렘 + 모자/상의/신발/장갑/반지) 시작 → 원작 풀 슬롯(14~16부위) 무중단 확장 설계 |
| **장비 수급** | 사냥·보스 드랍 + 보스 코인 교환으로 상위 세트(기본 → 펜살리르 → 카루타 → 앱솔랩스 → 아케인셰이드) 획득 |
| **3대 강화** | **주문서(주문의 흔적 풀 스펙)** + **스타포스(KMS 15성~ 파괴, 스페어 12성 복구)** + **윗잠재 큐브(천장 포함, 에디셔널 추후 확장)** |
| **리텐션/소셜** | **오프라인 방치 보상(최대 12시간)** + **전투력/레벨 랭킹(`SortableDataStorage`)** + **장비 도감 수집 보너스** *(전체 강화 공지 미사용)* |

## 2. 코어 루프 (Core Loop)

```
[공용 필드 자동사냥 (또는 오프라인 방치)]
   - 헤네시스 사냥터 등 실제 메이플 맵에서 자동 이동·점프·스킬 시전
   - 1대 이상 타격 시 개인별 경험치 / 메소 / 주문의 흔적 / 큐브 / 장비 획득
        │
        ▼
[마을(헤네시스) 정비 & 3대 강화]
   ① 주문서 작: 100/70/30/15% + 순백 10% + 이노센트 50% + 황금 망치
   ② 스타포스: 업횟 0 해금 → 17성 / 22성 도전 (파괴 시 장비의 흔적 + 스페어 복구)
   ③ 큐브 잠재: 레어→에픽→유니크→레전드리 (등업 천장, 블랙 큐브 Before/After 선택)
   ④ 장비 도감 등록으로 영구 보너스 스탯 누적
        │
        ▼
[전직 & 상위 사냥터 / 1인 보스 돌파]
   - 1차(Lv.10) → 2차(Lv.30) → 3차(Lv.60) → 4차(Lv.100) 스킬 자동 해금
   - 개인 인스턴스 보스 클리어 → 보스 코인 & 상위 세트 장비·스페어 파밍
   - 실시간 전투력/레벨 랭킹 갱신
        │
        └─────────▶ (반복)
```

## 3. 전투·스킬·전직 시스템

### 3.1 자동사냥 AI (`AutoHuntComponent`)
- **타겟 탐색:** 현재 맵의 살아있는 몬스터 중 같은 발판 우선 → 가장 가까운 몬스터 선택
- **이동/추적:** 좌우 이동 및 높이 차가 있을 경우 점프/발판 추적 (간단한 A*/발판 휴리스틱)
- **스킬 우선순위:**
  1. 버프 스킬 미적용 시 최우선 시전
  2. 범위 내 몬스터 2마리 이상 + 광역기 쿨타임 완료 시 광역기 시전
  3. 기본 주력기 시전
- **수동 개입:** 방향키/점프/스킬 키 입력 시 즉시 자동 이동 중단 → `autoResumeDelay = 2.0초` 경과 후 자동사냥 재개 (ON/OFF 토글 버튼 제공)

### 3.2 전직 및 스킬 로드맵 (단일 모험가 기준)
| 전직 | 해금 레벨 | 해금 스킬 | 역할 |
| :--- | :---: | :--- | :--- |
| **초보자** | Lv.1 | 기본 베기 | 근접 단일/소범위 평타 |
| **1차 전직** | Lv.10 | 파워 스트라이크(주력) / 슬래시 블러스트(다수기) | 초반 사냥 속도 대폭 상승 |
| **2차 전직** | Lv.30 | 부스터(공속 버프) / 돌진형 범위기 | 이동·사냥 템포 향상 |
| **3차 전직** | Lv.60 | 강화 주력기 / 크리티컬·공격력 패시브 | 중반 사냥터 돌파 |
| **4차 전직** | Lv.100 | 주력 보스기 / 맵 광역기(쿨타임) / 메이플 용사(주스탯% 버프) | 후반 사냥 및 보스 핵심 |

## 4. 장비 슬롯 & 세트 성장 구조

### 4.1 1차 핵심 8부위 (확장 가능 슬롯 구조)
| 슬롯 ID | 이름 | 주문서 | 스타포스 | 잠재능력 핵심 유효옵 |
| :--- | :--- | :---: | :---: | :--- |
| `Weapon` | 무기 | 공격력/주스탯 | O | 공%, 보공%, 방무% |
| `SubWeapon` | 보조무기 | X (또는 선택) | X | 공%, 보공%, 방무% |
| `Emblem` | 엠블렘 | X | X | 공%, 방무% *(보공 제외)* |
| `Hat` | 모자 | 주스탯/HP | O | 주스탯%, 올스탯% |
| `Top` | 상의(한벌옷) | 주스탯/HP | O | 주스탯%, 올스탯% |
| `Shoes` | 신발 | 주스탯/이속 | O | 주스탯%, 올스탯% |
| `Gloves` | 장갑 | 주스탯/공격력 | O | **크리티컬 데미지%**, 주스탯% |
| `Ring1` | 반지 | 주스탯/공격력 | O | **메소 획득량%**, **드랍률%**, 주스탯% |

> **확장성 설계:** 인벤토리/장착 데이터는 `equipped[slotId]` 딕셔너리 구조로 구현하여, 추후 `Pants`, `Cape`, `Shoulder`, `Belt`, `Earring`, `Pendant1`, `Ring2~4` 등을 스키마 마이그레이션 없이 추가할 수 있게 합니다.

### 4.2 장비 티어 & 세트 효과 (2/4/6세트)
1. **Lv.10~60 (입문/초반):** 초보자/모험가 장비 — 헤네시스 사냥터 드랍 & 마을 상점 구매 (스페어 수급 쉬움)
2. **Lv.140 (펜살리르):** 중반 공용 사냥터 드랍 — 본격적인 15~17성 & 에픽/유니크 진입
3. **Lv.150 (카루타):** 루타비스 보스 드랍/코인 교환 — 무기·모자·상의 3세트 핵심
4. **Lv.160 (앱솔랩스):** 중상위 보스 코인 교환 — 17~22성 구간
5. **Lv.200 (아케인셰이드):** 엔드 보스 코인 교환 — 최종 22성 + 레전드리 3줄 종결

## 5. 공용 사냥터, 보스, 오프라인 보상, 랭킹, 도감

### 5.1 공용 사냥터 보상 규칙 (타격 기여 방식)
- 서버의 몬스터 컴포넌트에 `hitContributors[userId] = true` 테이블을 유지
- 몬스터 사망 시 기여한 모든 유저에게 **개인별로 독립된 경험치 / 메소 / 주문의 흔적 / 큐브 / 장비 드랍** 지급 (유저 간 드랍 쟁탈 없음)
- 맵 내 몬스터 수 유지 리스폰 주기를 짧게(예: 2~3초) 설정해 다수 유저가 함께 사냥해도 쾌적함 유지

### 5.2 오프라인 방치 보상
- 플레이어 저장 데이터에 `lastSaveEpoch`와 `lastHuntingMapId` 기록
- 재접속 시 서버에서 `elapsed = min(now - lastSaveEpoch, 12 * 3600)` 계산 (최소 60초 이상일 때 정산 팝업 표시)
- 마지막 사냥터의 분당 기대 경험치·메소·주문의 흔적 × 오프라인 효율(예: 80%) 일괄 지급

### 5.3 전투력 / 레벨 랭킹 & 장비 도감
- **랭킹 보드:** `DataStorageService:GetSortableDataStorage("Ranking_CombatPower")` 및 `"Ranking_Level"`에 주기적/강화 직후 갱신, UI에서 Top 50 + 내 순위 조회
- **장비 도감:** 처음 획득한 장비 `itemId`를 `codexUnlocked[itemId] = true`로 영구 기록 → 수집 개수/세트 완성도에 따라 영구 패시브 스탯(주스탯+, 공격력+, 크뎀%) 부여

## 6. 개발 마일스톤

### Milestone 1 (MVP 1차 — 첫 플레이 가능 빌드)
1. **맵 구성:** 헤네시스(`100000000`, 마을) + 헤네시스 사냥터 1(`921170004`, 공용 사냥터) 포탈/빠른이동 연결
2. **전투 & 방치 루프:** 사냥터 몬스터 빠른 리젠, 타격 기여 개인 보상, 자동사냥 AI(+수동 개입), 레벨업 & 1차 스킬
3. **장비 & 저장:** 8부위 장비 데이터 모델, 장착/스탯 합산/전투력 계산, `DataStorageService` 저장/불러오기
4. **3대 강화 완성:** 주문서(주문의 흔적 풀 스펙) + 스타포스(15성~ 파괴 & 스페어 복구) + 큐브(윗잠재 + 천장 + 블랙큐브 선택) 통합 UI

### Milestone 2 (성장·소셜 확장)
- 전직 2~4차 스킬, 오프라인 12시간 정산 팝업, 전투력/레벨 랭킹 보드, 장비 도감 UI

### Milestone 3 (콘텐츠 확장)
- 사냥터 추가(엘리니아/페리온/루디브리엄/리프레), 1인 인스턴스 보스전(자쿰→카루타→스우), 보스 코인 상점, 원작 풀 슬롯 및 에디셔널 잠재 확장

# 3대 핵심 강화 시스템 상세 스펙 (v1.0 — 확정)

> **강화 순서 (원작 동일):**  
> **장비 획득 → ① 주문서 작 (업횟 0 달성) → ② 스타포스 강화 → ③ 잠재능력 & 큐브** *(잠재능력은 언제든 병행 가능)*  
> **보안 원칙:** 모든 확률 판정·재화 차감·아이템 상태 변경은 **`[server only]`** 로직(`EnhanceLogic`)에서 처리하며, 완료 즉시 저장합니다.

---

## 1. 주문서 시스템 (주문의 흔적 풀 스펙)

### 1.1 규칙
- 장비별 기본 `upgradeMax` 보유 (예: 무기 8회, 모자/상의/신발/장갑 7회, 반지 5회; 보조무기/엠블렘 0회)
- 강화 시도 시 성공/실패와 무관하게 `upgradeRemaining -= 1`
  - 성공: `scrollSuccess += 1`, 해당 주문서의 공격력/주스탯 보너스 누적
  - 실패: `scrollFail += 1` (순백의 주문서 복구 대상)
- **황금 망치:** 장비당 최대 1회 사용 가능 (`hammerUsed = true`), `upgradeMax += 1`, `upgradeRemaining += 1`

### 1.2 주문의 흔적 강화 테이블
| 주문서 | 성공률 | 무기 (공격력 / 주스탯) | 방어구·장신구 (주스탯 / 공격력) | 소모 주문의 흔적 |
| :--- | :---: | :---: | :---: | :---: |
| **100% 작** | 100% | +3 / +1 | +3 / +0 | 100 |
| **70% 작** | 70% | +5 / +2 | +5 / +0 | 200 |
| **30% 작** | 30% | +7 / +3 | +7 / +1 | 400 |
| **15% 작** | 15% | +9 / +4 | +10 / +2 | 700 |

### 1.3 특수 주문서
| 주문서 | 성공률 | 소모 주문의 흔적 | 효과 |
| :--- | :---: | :---: | :--- |
| **순백의 주문서 10%** | 10% | 2,000 | `scrollFail > 0`일 때 `scrollFail -= 1`, `upgradeRemaining += 1` |
| **이노센트 주문서 50%** | 50% | 5,000 | 주문서 보너스 + 업횟 + 스타포스 초기화 *(잠재능력·황금망치 유지 여부: 원작 기준 황망 포함 초기화, 잠재능력 유지)* |
| **황금 망치 100%** | 100% | 3,000 | `hammerUsed == false`일 때 업횟 +1 |

### 1.4 방치형 편의 UX
- **1회 강화** / **연속 강화(업횟 소진까지 자동 진행)** 버튼 제공
- 서버에서 연속 강화 요청 시 1회 요청으로 루프 계산 후 결과 요약(성공 N회 / 실패 M회) 반환

## 2. 스타포스 시스템 (최신 KMS + 스페어 전승 복구)

### 2.1 해금 조건 & 최대 성수
- **해금 조건:** `upgradeRemaining == 0`이고 `isDestroyed == false`인 강화 가능 슬롯
- **장비 레벨(`reqLevel`)별 최대 성수:**

### 2.3 핵심 보조 메커니즘
- **찬스 타임:** 2회 연속 등급 하락(`consecutiveFailDrop == 2`) 시 다음 1회 **성공 확률 100%** (파괴 0%)
- **스타캐치:** 토글 ON 시 타이밍 미니게임 성공 시 `successRate = successRate * 1.05` (실패/하락/파괴 확률은 잔여 비율에 따라 축소)
- **파괴 방지 (15~16성):** 체크 시 메소 비용 **×2**, 파괴 확률을 유지(15성) 또는 하락(16성)으로 이전
- **장비의 흔적 & 스페어 전승 복구:**
  - 파괴 발생 시 장비가 삭제되지 않고 `isDestroyed = true`, `star = 0` 상태의 **"장비의 흔적"**으로 전환 (주문서 작·잠재능력·천장 카운트 보존, 장착 해제)
  - 인벤토리에 보유한 **동일 `itemId` 장비(스페어)** 1개를 소모하여 전승하면 `isDestroyed = false`, **`star = 12`**로 즉시 복구!

### 2.4 성수별 스탯 증가 공식 (간략화)
- **1~15성:** 매 성수당 주스탯 `+2~3` (무기는 현재 공격력의 2% + 1 추가)
- **16~22성 (핵심 성장 구간):**
  - 16성: 주스탯 +11, 공격력 +9
  - 17성: 주스탯 +11, 공격력 +10
  - 18성: 주스탯 +11, 공격력 +11
  - 19성: 주스탯 +11, 공격력 +12
  - 20성: 주스탯 +11, 공격력 +13
  - 21성: 주스탯 +11, 공격력 +14
  - 22성: 주스탯 +11, 공격력 +15

## 3. 잠재능력 & 큐브 시스템 (윗잠재 + 등업 천장)

### 3.1 등급 & 줄 규칙
- **4등급:** `Rare` (파랑) → `Epic` (보라) → `Unique` (노랑) → `Legendary` (초록)
- 모든 장비는 획득/감정 시 **기본 3줄** 잠재능력 부여 (`Rare` 등급 시작)
- **줄별 등급 규칙:**
  - 1번째 줄: 현재 등급 옵션 100% 확정
  - 2번째 줄: 현재 등급 10% (이탈) / 하위 등급 90%
  - 3번째 줄: 현재 등급 5% (이탈) / 하위 등급 95%

### 3.2 큐브 종류, 등급업 확률 & 천장 (확정 등업 카운트)
| 큐브 | 최대 등급 | 특징 | 레어→에픽 | 에픽→유니크 | 유니크→레전드리 | 천장 (레→에 / 에→유 / 유→레) |
| :--- | :---: | :--- | :---: | :---: | :---: | :---: |
| **수상한 큐브** | 에픽 | 사냥 대량 드랍 | 1.5% | - | - | 50회 / - / - |
| **장인의 큐브** | 유니크 | 보스/사냥 드랍 | 5.0% | 1.5% | - | 25회 / 60회 / - |
| **명장의 큐브** | 레전드리 | 보스 드랍 | 8.0% | 2.0% | 0.5% | 15회 / 45회 / 100회 |
| **레드 큐브** | 레전드리 | 즉시 적용, 메소/상점 수급 | 6.0% | 2.0% | 0.6% | 20회 / 45회 / 90회 |
| **블랙 큐브** | 레전드리 | **Before / After 선택** + 최고 등업률 | 15.0% | 4.0% | 1.8% | 10회 / 25회 / 50회 |

- **천장 규칙:** 장비별 현재 등급에서의 누적 등업 실패 횟수(`cubePityCount`)가 해당 큐브의 천장에 도달하면 **다음 1회 확정 등급업**, 등급업 성공 시 `cubePityCount = 0` 리셋
- **블랙 큐브 흐름:** 서버가 후보 옵션(`pendingPotential`)을 생성해 클라이언트에 `BEFORE / AFTER` 전송 → 유저가 **[기존 유지]** 또는 **[새 옵션 적용]** 선택 시 확정

### 3.3 부위별 옵션 풀 (단일 모험가 통합 스탯 기준)
- **무기 / 보조무기 (`Weapon`, `SubWeapon`):**
  - 레전드리: 공격력 +12%, 보스 데미지 +35% / +40%, 방어율 무시 +35% / +40%, 데미지 +12%, 크리티컬 확률 +12%
  - 유니크: 공격력 +9%, 보스 데미지 +30%, 방어율 무시 +30%, 데미지 +9%, 주스탯 +9%
  - 에픽: 공격력 +6%, 방어율 무시 +15%, 데미지 +6%, 주스탯 +6%
  - 레어: 공격력 +3%, 데미지 +3%, 주스탯 +3%
- **엠블렘 (`Emblem`):** 무기/보조와 동일하되 **보스 데미지 제외** (원작 고증)
- **장갑 (`Gloves`):**
  - 레전드리: **크리티컬 데미지 +8%**, 주스탯 +12%, 올스탯 +9%, 방어력 +12%
  - 유니크/에픽/레어: 주스탯 +9%/+6%/+3%, 크리티컬 확률 등
- **반지 (`Ring1`~):**
  - 레전드리: **메소 획득량 +20%**, **아이템 드랍률 +20%**, 주스탯 +12%, 올스탯 +9%
- **모자 / 상의 / 신발 (`Hat`, `Top`, `Shoes`):**
  - 레전드리: 주스탯 +12%, 올스탯 +9%, 최대 HP +12%, 방어력 +12%

## 4. 확장 대비 장비 인스턴스 스키마 (`EquipInstance`)

```lua
local EquipInstance = {
    uid = "eq_0001",
    itemId = "weapon_henesys_sword",
    slot = "Weapon",            -- 추후 Pants, Cape, Ring2 등 자유 확장
    reqLevel = 30,

    -- ① 주문서 작
    upgradeMax = 8,
    upgradeRemaining = 0,
    hammerUsed = false,
    scrollSuccess = 8,
    scrollFail = 0,
    scrollBonus = { mainStat = 16, att = 40, maxHp = 0 },

    -- ② 스타포스
    star = 17,
    isDestroyed = false,
    consecutiveFailDrop = 0,

    -- ③ 윗잠재능력
    potentialGrade = "Legendary",   -- Rare / Epic / Unique / Legendary
    cubePityCount = 0,
    potentials = {
        { stat = "attPct", value = 12 },
        { stat = "bossDmg", value = 35 },
        { stat = "attPct", value = 9 },
    },
    pendingPotential = nil,         -- 블랙 큐브 선택 대기 버퍼

    -- ④ 에디셔널 잠재능력 (후반 확장 예약 필드)
    additionalPotentialGrade = "None",
    additionalPotentials = {},
}
```

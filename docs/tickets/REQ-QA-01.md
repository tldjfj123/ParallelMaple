# REQ-QA-01: v1.0 통합 E2E 플레이테스트 · 마이그레이션 · 멀티 격리 & Private 출시 검증

- **도메인:** `QA` · **유형:** `[QA]` · **우선순위:** `P2`
- **선행 티켓:** `REQ-ARCH-01` ~ `REQ-BOSS-04` 전체 완료 후

## 1. 목표 (User Story)
ParallelMaple v1.0의 모든 시스템이 하나의 플레이 흐름으로 매끄럽게 연결되고, 콘솔 에러·데이터 유실·멀티플레이 간섭 없이 MSW 그룹 월드 Private 출시 가능한 품질인지 최종 검증한다.

## 2. E2E 검증 시나리오 (필수 통과)
1. **신규 유저 무지급 온보딩 (Lv.1 ~ Lv.30)**:
   - [ ] 장비 0개(맨손), 메소 0, 큐브 0, 기본 1펫, AP 5로 시작.
   - [ ] `Ch.1 헤네시스 사냥터 1`에서 맨손으로 몹 처치 → 첫 `카알 대검`/브론즈 장비 득템 → 장착.
   - [ ] 레벨업당 AP +5 지급, `S` 창 수동/자동 배분 및 `AP 초기화 주문서` 정상 동작.
   - [ ] Lv.10 1차 전직 → Lv.30 2차 전직(공짜 장비 미지급) → 상점(`B`)에서 Lv.30 보조무기 구매.
2. **24부위 풀 슬롯 · 3대 강화 · 세트 효과 · 인벤 정리**:
   - [ ] 착용 레벨 미달 장비 장착 차단, 한벌옷↔하의 상호 해제, 반지 4칸 자동 배치.
   - [ ] 주문서(100/70/30/15%, 연속작, 순백/이노/황망) → 스타포스(15성 파괴 → 장비의 흔적 → 미잠금 스페어 12성 복구) → 큐브(천장 & 블랙큐브 Before/After).
   - [ ] 잠금(🔒) 장비가 판매·분해·일괄 분해·스페어 복구에서 모두 보호됨.
   - [ ] `3카 5앱` + `보스 장신구` 세트 효과가 전투력과 스탯창에 정확히 합산됨.
3. **펫 성장 · 생존 · 오프라인 보상**:
   - [ ] 1펫 → 2펫(50만) → 3펫(200만) → 자석펫(1,000만) 순차 구매 및 `P` 토글 작동.
   - [ ] HP 50% 자동 포션(25% 파엘 우선), 포션 0개 사망 시 경험치 무손실 헤네시스 부활.
   - [ ] 60초 미만 미표시, 12시간 초과 상한 캡, 수령 연타 중복 지급 차단.
4. **1인 개인 사냥터 90스테이지 & 이벤트 4종**:
   - [ ] 2클라 멀티 테스트: 헤네시스 마을에서는 서로 보이고, 같은 `Ch.1` 사냥터에서는 완전 격리.
   - [ ] 3,000마리 처치 → 챕터 보스(60초 타임어택) 격파 → 다음 챕터 해금 & 주차 이동.
   - [ ] 엘리트 몬스터(100마리), 룬(경험치 2배 3분), 30분 버닝 필드, 도파민 상자 3택 1 정상 작동.
5. **1인 레이드 보스 5단계 & 코인 상점**:
   - [ ] 자쿰/혼테일/카루타/스우/루시드 5개 맵 입장, 패턴 1.2초 경고·회피, 방무/보공 적용.
   - [ ] 데카 소진/시간초과/포기 시 일일 횟수 미차감, 클리어 시에만 차감 및 KST 00:00 리셋.
   - [ ] 보스 코인으로 카루타/앱솔/아케인 및 보장 장비 교환 정상 동작.
6. **저장 호환 & 배포**:
   - [ ] 기존 `v2` 저장 유저 접속 시 크래시 없이 `v3` 자동 마이그레이션.
   - [ ] Static ↔ Instance 방 이동 왕복 10회 데이터 유실 0건.
   - [ ] MSW Maker Play Mode 서버/클라 콘솔 에러 0건 & 그룹 월드 `Sync to Remote Workspace` → Private 출시 테스트 완료.

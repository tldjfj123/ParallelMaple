# REQ-INVEN-02: 인벤창(`I`) 60칸 · 잠금/판매/분해 버튼 · 일괄 분해 확인 모달 UI

- **도메인:** `INVEN` · **유형:** `[UI]` · **우선순위:** `P1`
- **선행 티켓:** `REQ-ARCH-02`, `REQ-INVEN-01` · **병렬 가능:** `REQ-SHOP-03`, `REQ-BOSS-04`와 병렬 가능

## 1. 목표 (User Story)
플레이어가 인벤토리창(`I`)에서 장비 60칸을 페이지로 탐색하고, 잠금(🔒)·판매·분해·하위 장비 일괄 분해를 직관적으로 실행할 수 있다.

## 2. 상세 요구사항 (FR)
1. 인벤토리창(`I`)에 빅뱅 이후~현대 공식 **`UIWindow4`** 프레임 적용 및 `[장비]` 탭 상단에 용량 카운터 `(현재/60)`·페이지네이션 표시.
2. 각 장비 슬롯 표시 보강:
   - `item.locked == true`이면 좌상단 `🔒` 배지 표시.
   - `profile.level < item.reqLevel`이면 툴팁의 요구 레벨을 빨간색(`Lv.140 필요`)으로 표시.
   - `item.isDestroyed == true`이면 붉은 반투명 테두리 유지.
3. 장비 상세 액션 버튼 영역에 5개 버튼 배치:
   - `[장착]` · `[강화]` · `[잠금 / 해제]` · `[판매 (+메소)]` · `[분해 (+주흔)]`
4. 인벤토리 하단에 **`[하위 장비 일괄 분해]`** 버튼 추가 → 클릭 시 `UIPopup` 확인 모달로 `"미잠금·노강·레어 이하 장비 N개를 분해해 주문의 흔적 M개를 획득할까요?"` 미리보기 후 확인 시 `RequestBulkDismantle(profile.level)` 호출.
5. `[기타]` 탭에 보유 중인 **보스 코인 5종**(`자쿰/혼테일/루타비스/앱솔/아케인`) 수량도 함께 표시.

## 3. 예외 / 엣지 케이스
- 장착 중이거나 잠금된 장비 선택 시 `[판매]`, `[분해]` 버튼 비활성화.
- 빈 슬롯 선택 시 액션 버튼 전체 비활성화.

## 4. 수정 대상 파일 (`File Scope`)
- 수정: `workspaces/ParallelMaple/RootDesk/MyDesk/UICharacterWindows.mlua` *(필요 시 `IdleHUDGroup.ui` 인벤 버튼 슬롯만 최소 수정)*

## 5. Play Mode 완료 조건 (AC)
- [ ] `[잠금]` 토글 시 즉시 아이콘에 🔒가 붙고 `[판매]/[분해]` 버튼이 비활성화된다.
- [ ] `[하위 장비 일괄 분해]` 클릭 시 예상 개수와 주흔량이 정확히 계산된 확인 팝업이 뜬다.
- [ ] 착용 레벨 미달 장비에 빨간 레벨 경고가 정상 표시된다.

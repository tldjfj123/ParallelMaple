# REQ-HUNT-04: 길라잡이(`M`) 18챕터/스테이지/버닝 UI + 사냥터 상단 진행바 & 도파민 상자 팝업

- **도메인:** `HUNT` · **유형:** `[UI]` · **우선순위:** `P1`
- **선행 티켓:** `REQ-ARCH-02`, `REQ-HUNT-02`, `REQ-HUNT-03` · **병렬 가능:** `REQ-BOSS-04`, `REQ-SHOP-03`과 병렬 가능

## 1. 목표 (User Story)
플레이어가 길라잡이(`M`)에서 18개 챕터의 해금 상태·스테이지(1~5)·버닝 불꽃 배지를 한눈에 보고 주차 이동하며, 사냥터 상단 진행바에서 `X/3,000` 처치·챕터 보스 도전·도파민 상자 3택 1을 바로 조작한다.

## 2. 상세 요구사항 (FR)
1. **길라잡이창(`M`, `UINavigationWindows`) 개편**:
   - 각 챕터 행에 `Ch.N`, 지역명, 요구 레벨, 스타포스 배지(`★30/55/80/140`), **로테이션 버닝 배지(`🔥 +N0%`)**, 특화 태그 표시.
   - 해금된 챕터 클릭 시 `Stage 1 ~ 5` 선택 버튼 노출 → 클릭 시 `RequestEnterHuntingStage(chapter, stage)` 호출.
   - 상단 `[헤네시스 마을 귀환]` 버튼은 `RequestReturnTown()` 호출.
2. **사냥터 상단 미니 진행바 (`IdleHUDGroup.ui` 사냥터 체류 시 표시)**:
   - 현재 위치 (`Ch.13-3 커닝타워`) + 처치 게이지 (`1,840 / 3,000`) + 3,000 달성 시 반짝이는 **`[다음 단계 / 챕터 보스 도전!]`** 버튼.
   - 챕터 보스 진행 중에는 **보스 HP 바 + 남은 시간(60초)**로 자동 전환.
   - 우측: **도파민 상자 게이지 (`74%`, `pending > 0` 시 반짝임 + 배지 `N`)** + **룬 버프 타이머 (`2x EXP 02:41`)**.
3. **도파민 상자 3택 1 팝업**:
   - 상자 아이콘 클릭 시 3장의 보상 카드(주흔 묶음 / 레드·블랙 큐브 / 메소 주머니) 표시 → 선택 시 `RequestClaimTreasureCard(idx)` 호출.

## 3. 예외 / 엣지 케이스
- 마을(`TileMapTemplate`)이나 레이드 보스 맵에 있을 때는 사냥터 상단 진행바를 숨긴다.
- 미해금 챕터/스테이지는 잠금 아이콘(🔒)으로 비활성화.

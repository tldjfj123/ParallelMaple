# REQ-EQUIP-04: 장비창(`E`) 24슬롯 격자 개편 + 세트 배지 + 강화창 24슬롯 연동

- **도메인:** `EQUIP` · **유형:** `[UI]` · **우선순위:** `P1`
- **선행 티켓:** `REQ-ARCH-02`, `REQ-EQUIP-02` · **병렬 가능:** `REQ-SHOP-03`, `REQ-SURV-03`, `REQ-BOSS-04`와 병렬 가능

## 1. 목표 (User Story)
장비창(`E`)을 현대 메이플 원작의 24부위 5열 격자 레이아웃으로 개편하고, 한벌옷 비활성 표시·활성 세트 배지·강화창(`U`) 장착 목록 연동을 완성한다.

## 2. 상세 요구사항 (FR)
1. `IdleHUDGroup.ui`의 장비창(`E`) 내부에 24부위 슬롯 칸 배치 (원작 5열 그리드 배치 고증):
   - 반지4 · 모자 · 엠블렘 · 뱃지 / 펜던트2 · 얼굴 · 눈 · 귀고리 / 무기 · 상의 · 하의 · 보조무기 / 장갑 · 망토 · 신발 · 벨트 / 견장 · 포켓 · 훈장 · 심장
2. 각 슬롯에 잠재 등급 테두리 컬러 + `★성수` 배지 표시. 빈 슬롯은 회색 실루엣 라벨 표시.
3. 한벌옷 장착 시 `Pants` 슬롯은 반투명 비활성 + `"한벌옷 착용중"` 표시.
4. 장비창 하단에 `stats.activeSets` 기반 활성 세트 배지 표시 (예: `카루타 3/4 · 앱솔 5/7 · 보장 5/9`).
5. `UIEnhanceController`의 좌측 장착 장비 목록이 8부위가 아닌 24부위(`SlotOrder`)를 전부 순회하도록 확장.

## 3. 예외 / 엣지 케이스
- 미장착 슬롯 클릭 시 에러 없이 상세 툴팁에 `"미장착 슬롯"` 안내 표시.
- 24개 슬롯이 작은 해상도에서도 겹치지 않도록 44×44px 균등 간격으로 정렬.

## 4. 수정 대상 파일 (`File Scope`)
- 수정: `workspaces/ParallelMaple/RootDesk/MyDesk/UICharacterWindows.mlua`, `workspaces/ParallelMaple/RootDesk/MyDesk/UIEnhanceController.mlua`, `workspaces/ParallelMaple/ui/IdleHUDGroup.ui`

- [ ] 한벌옷 착용 시 하의 칸이 비활성화되고, 카루타 상·하의 착용 시 둘 다 정상 표시된다.
- [ ] 강화창(`U`)에서도 반지2~4, 망토, 견장, 하의 등 신규 슬롯 장비를 선택해 강화할 수 있다.

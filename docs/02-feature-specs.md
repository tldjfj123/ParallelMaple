## F1. 전투 · 자동사냥 · 자동포션 · 사망 규칙

### F1.1 자동사냥 & 수동 병행 `[As-Is 완료]`
- **토글**: `F` 키 또는 HUD 버튼으로 ON/OFF.
- **타겟 탐색**: 현재 맵에서 살아있는 몬스터 중 같은 발판(`|dy| <= 1.35`) 우선, 없으면 `|dx| + |dy| * 2.5` 최소 대상 추적.
- **스킬 연계**: 현재 전직 티어 기준 해금된 최고 효율 광역기/주력기 자동 시전 (`AutoHuntComponent:PickBestAutoSkillId`).
- **수동 개입**: 방향키/점프/스킬키 입력 시 즉시 `ManualPauseUntil = now + 2.0초` (스킬키는 `1.2초`) 유예 후 자동 복귀.
- **펫 시스템 & 자석펫 해금 (`[수정 필요]`)**:
  - **초기 상태**: 신규 유저는 **기본 펫 1마리**(일반 근거리 줍기, `petCount = 1`, `magnetPetUnlocked = false`)로 시작합니다.
  - **멀티펫 확장 (NPC 상점 메소 구매)**:
    - 2번 펫 해금 (`petCount = 2`): **500,000 메소**
    - 3번 펫 해금 (`petCount = 3`, 최대): **2,000,000 메소**
  - **자석펫 업그레이드 (NPC 상점 메소 구매)**:
    - 조건: 3펫 보유 또는 단독 구매 가능 (`magnetPetUnlocked = true`): **10,000,000 메소** *(중후반 방치 파밍의 핵심 메소 목표!)*
    - 해금 후 `P` 키로 광역 자석 루팅(`9.5m × 5.2m`) ON/OFF 토글 가능. 미해금 상태에서 `P` 입력 시 상점 안내 토스트 출력.

### F1.2 공용 사냥터 타격 기여 보상 `[As-Is 완료]`
- 몬스터 피격 시 `Monster.HitContributors[userId] = true` 기록.
- 몬스터 사망 시 `0.15초` 후 기여자 전원에게 **개인별 독립 경험치 + 개인 바닥 드랍** 지급.

### F1.3 자동 포션 & 피격/사망 처리 `[신규 구현 / 수정 필요]`
- **기존 임시 로직 제거**: `PlayerDataLogic:RecalculateStats` 내부의 `Hp < MaxHp * 0.65` 시 강제 풀회복 코드를 제거합니다.
- **자동 포션 규칙 (서버 권위, `PlayerDataLogic` 또는 `SurvivalLogic`)**:
  - 플레이어가 피격되어 `Hp > 0`이고 `Hp / MaxHp <= profile.autoPotionThreshold` (기본값 `0.50`, 추후 설정 가능)일 때 서버가 자동 포션 발동.
  - 내부 쿨타임: `1.0초` (연속 피격 시 포션 증발 방지).
  - 포션 선택 우선순위: 보유 중인 포션 중 **레벨 구간에 맞는 기본 포션 우선** (`red_potion` → `white_potion` → `blue_potion` → `power_elixir`, 단 `Hp/MaxHp <= 0.25` 위급 시 `power_elixir` 우선 사용).
  - 보유 포션이 0개이면 클라이언트 토스트 `"⚠️ 보유한 포션이 없습니다! 마을 상점에서 보충하세요."` (30초 쿨타임 알림).
- **사망 처리**:
  - **일반 사냥터**: `Hp <= 0` 도달 시 경험치/메소 패널티 **없음**. `2.0초` 후 `Hp = MaxHp`로 회복하여 마을(`TileMapTemplate`)로 이동 + 클라이언트 자동사냥 OFF + 토스트 `"체력이 0이 되어 헤네시스로 귀환했습니다."`.
  - **보스전 인스턴스**: F6 보스전 데스카운트 규칙 따름.
- **완료 조건 (AC)**:
  - [ ] 피격으로 HP가 50% 이하가 되면 서버에서 포션 1개가 자동 차감되고 HP가 회복되며 클라이언트에 동기화된다.
  - [ ] 포션이 모두 소진되어 HP가 0이 되면 일반 사냥터에서는 경험치 손실 없이 헤네시스로 부활한다.

### F2.1-B 수동 스탯(AP) 배분 시스템 (`STR / DEX / INT / LUK`) `[신규 구현]`
- **초기 스탯**: `baseStats = { str = 4, dex = 4, int = 4, luk = 4 }`, `unspentAp = 5` (Lv.1 시작 시 5포인트 보유).
- **레벨업 보상**: 1레벨 상승할 때마다 `unspentAp += 5`.
- **배분 RPC**:
  - `RequestAllocateAp(statKey, amount)`: 서버에서 `unspentAp >= amount` 검증 후 `baseStats[statKey] += amount`, `unspentAp -= amount`, `RecalculateStats()` 실행.
  - `RequestAutoAllocateAp()`: 남은 `unspentAp` 전부를 현재 직업의 주스탯(`str`)에 일괄 배분.
  - `RequestResetAp()`: NPC 상점에서 구매한 `AP 초기화 주문서` 1개 소모 → 4스탯을 모두 4로 초기화하고 총 AP 반환.
- **데미지 공식 반영 (원작 본메 기준)**:
  - 전사 주스탯 = `totalStr`, 부스탯 = `totalDex`
  - **`statValue = (totalStr * 4) + totalDex`**
  - 기본 데미지: `base = (statValue * totalAtt) / 135.0`
  - 맨손(`Weapon` 미장착) 시에도 최소 기본 공격력 `att = 12`가 보장되어 Lv.1 헤네시스 사냥터 1 몬스터를 직접 잡아 첫 장비를 득템할 수 있습니다.

### F2.2 데미지 & 전투력 공식
- **기본 데미지**: `base = ((totalStr * 4 + totalDex) * totalAtt) / 135.0`
- **배율**: `dmgMult = (1 + dmgPct/100) * (1 + finalDmgPct/100)`
- **스타포스 필드 보정(`sfMult`)**: 스타포스 요구 맵에서 충족 시 `1.25`, 미달 시 `0.72`
- **보스 대상 추가 보정 (`[신규 구현]`)**:
  - `defender`가 보스 몬스터일 경우:
    - 보스 데미지 합산: `dmgMult = (1 + (dmgPct + bossDmgPct)/100) * (1 + finalDmgPct/100)`
    - 방어율 무시(방무) 공식: `effectiveDef = bossPdr * (1 - iedPct / 100)`, `iedMult = max(0.05, 1 - effectiveDef / 100)`
- **콤보 어택**: 2차 이상 적중 시 1스택 증가(최대 5/7/10), 스택당 `최종 데미지 +6%`, `추가 경험치 +1%`.
- **레벨업**: 최대 Lv.200, KMS 1배 경험치 테이블. 레벨업 시 AP +5 지급 + HP 완전 회복 + 빛기둥 이펙트 + 반경 `4.6m × 2.6m` 내 일반 몬스터 최대 8마리 즉사 충격파.

## F3. 1인 개인 사냥터 (`18챕터 × 5스테이지 = 90스테이지`) & 사냥 이벤트 `[개편 / 신규 구현]`

### F3.1 공용 마을 ↔ 1인 개인 사냥터 인스턴스 구조
- **헤네시스 마을(`TileMapTemplate`)**: 공용 Static Room (유저 간 만남·채팅·정비).
- **사냥터 18개 (`Ch.1` ~ `Ch.18`)**: 전부 `InstanceMap`으로 설정하여 **유저별 1인 개인 사냥터 룸(`HuntRoom_<userId>`)**에 묶어 운용합니다.
  - 스틸 0%, 타 유저 이펙트/동기화 부하 0%.
  - 한 번 사냥터 룸에 입장하면 해금된 챕터/스테이지 간에는 마을을 거치지 않고 `M` 길라잡이로 원클릭 즉시 워프.

### F3.2 챕터 × 스테이지 돌파 & 주차 루프 (메이플 키우기 컨버트)
- **볼륨**: 기존 18개 사냥터 맵 = **`Ch.1` ~ `Ch.18`**, 각 챕터마다 **`Stage 1 ~ 5`** (총 **90스테이지**).
- **스테이지 스케일링**: 동일 맵 안에서 `stage (1~5)`에 따라 몬스터 스펙/보상 동적 배율 적용:
  - `Stage 1`: `1.00x` / `Stage 2`: `1.18x` / `Stage 3`: `1.38x` / `Stage 4`: `1.62x` / `Stage 5`: `1.90x` *(경험치/메소 보상도 `1.00x ~ 1.65x` 단계 상승)*
- **돌파 규칙**:
  - 현재 최고 스테이지에서 일반 몬스터 **3,000마리** 처치 시 상단 **`[다음 단계 도전]`** (`Stage 1~4`) 또는 **`[챕터 보스 도전!]`** (`Stage 5`) 버튼 활성화.
  - `Stage 5` 챕터 보스 도전 시 현재 개인 맵에서 일반 몹을 잠시 숨기고 **챕터 돌파 보스**(제한시간 **60초** 타임어택)를 소환!
  - 클리어 시 **다음 챕터 `Stage 1` 해금** + 최초 돌파 보상(메소 + 주흔 + 큐브), 실패 시 패널티 없이 현재 스테이지 방치 복귀.
  - 이미 개방된 모든 챕터/스테이지는 `M` 길라잡이에서 자유롭게 **주차 이동** 가능 (레벨 요건 `profile.level >= chapter.reqLevel` 병행).

### F3.3 사냥터 도파민 장치 4종 `[신규 구현]`
1. **엘리트 몬스터**: 개인 사냥터에서 일반 몹 **100마리** 처치마다 거대 엘리트 몬스터 1마리 소환 (HP 15배, 경험치 10배 + **주흔/큐브/장비 확정 대량 드랍**).
2. **룬 (경험치 2배)**: 10분마다 사냥터 발판 위에 랜덤 룬 1개 생성 → 접근 후 `Space`/클릭 발동 시 **3분간 경험치 +100% (2배)** *(화면 확인 유저 보너스)*.
3. **로테이션 버닝 필드**: 서버 기준 **30분마다** 18개 챕터 중 랜덤 4~5곳에 **버닝 1~10단계 (추가 경험치 +10% ~ +100%)** 적용 (`M` 창에 불꽃 배지 표시).
4. **사냥 도파민 상자 *(여정의 보물 컨버트)***: 몹 처치마다 누적 게이지 충전 (`100%` 도달 시 상단 알림 배지 반짝임, 최대 5회 누적 보관) → 클릭 시 **보상 카드 3택 1** *(주문의 흔적 묶음 / 레드·블랙 큐브 / 메소 주머니 — 현재 챕터가 높을수록 보상 증가!)*.

### F3.4 스타포스 사냥터 & 장비 드랍풀
- **스타포스 챕터 4곳** (`Ch.11` 30★ / `Ch.12` 55★ / `Ch.13` 80★ / `Ch.16` 140★): 충족 시 데미지 `1.25배` + 추경 `+15%`, 미달 시 `0.72배`.
- **장비 드랍풀 원칙**: 일반 사냥터는 **KMS 원작 Lv.10 ~ Lv.140 펜살리르 세트까지만** 드랍. 카루타(150)/앱솔랩스(160)/아케인셰이드(200)/보스 장신구는 F6 1인 레이드 보스 & 보스 코인 상점 전용. 상세 매핑은 [docs/03-data-reference.md](docs/03-data-reference.md) 참조.

## F4. 장비 · 정통 점진 성장 · 세트 효과 · 인벤토리 정리 `[수정 필요 / 신규 구현]`

### F4.0 현대 메이플 풀 슬롯 (24부위 전부 오픈) `[신규 구현]`
- 장비창은 처음부터 **현대 메이플 정식 24부위**를 전부 개방합니다 (`equipped[slotId]` 딕셔너리):
  - **무기·특수 (3)**: `Weapon` (무기), `SubWeapon` (보조무기), `Emblem` (엠블렘)
  - **방어구 (7)**: `Hat` (모자), `Top` (상의/한벌옷), `Pants` (하의), `Shoes` (신발), `Gloves` (장갑), `Cape` (망토), `Shoulder` (견장)
  - **장신구 (10)**: `Ring1`~`Ring4` (반지 4), `Pendant1`~`Pendant2` (펜던트 2), `Face` (얼굴장식), `Eye` (눈장식), `Earring` (귀고리), `Belt` (벨트)
  - **특수 장착 (4)**: `Pocket` (포켓), `Badge` (뱃지), `Medal` (훈장), `AndroidHeart` (기계심장)
- **한벌옷 규칙**: 펜살리르(`pensalir_top`) 등 한벌옷 장비는 `Top` 슬롯에 장착되며 `isOverall = true`일 경우 `Pants` 슬롯과 공존하지 않습니다(카루타 상·하의 분리 시 `Top` + `Pants` 동시 장착 가능).
- **다중 슬롯 자동 배치 (반지 4 / 펜던트 2)**: `Ring` 계열 장비 장착 요청 시 빈 슬롯(`Ring1`→`Ring4`)에 우선 장착하고, 모두 차 있으면 선택한 슬롯(기본 `Ring1`)을 교체합니다. (`Pendant1`~`2` 동일)

### F4.1 신규 유저 초기 상태 개편 (무지급 100% 자급자족) `[수정 필요]`
- **공짜 지급 전면 제거**:
  - 레벨: `Lv.1`, `jobTier = 0` (초보자)
  - 기본 스탯: `baseStats = { str = 4, dex = 4, int = 4, luk = 4 }`, `unspentAp = 5`
  - 초기 장비: **0개 (맨손 시작!)** — `Ch.1 헤네시스 사냥터 1`에서 직접 사냥해 첫 장비 득템 또는 메소 파밍 후 상점 구매
  - 초기 펫: `petCount = 1` (기본 펫 1마리), `magnetPetUnlocked = false`
  - 초기 재화: `meso = 0`, `spellTrace = 0`, `cubes = {}`, `potions = { red_potion = 10 }` *(최소 초반 생존용 빨간 포션 10개만 보유 — 원할 시 0개로 조정 가능)*
  - 기존 테스트 계정이 저장되어 있는 경우 스키마 `version = 3`으로 마이그레이션하되 기존 장비는 유지합니다.

### F4.2 착용 레벨 제한 강제 `[신규 구현]`
- `RequestEquipItem(uid)`에서 `profile.level < item.reqLevel`이면 장착 거부 + 토스트 `"🔒 Lv.<reqLevel>부터 장착할 수 있는 장비입니다!"`.

### F4.4 인벤토리 잠금 / 판매 / 분해 `[신규 구현]`
- **인벤토리 최대 칸수**: 장비 60칸으로 확장 (기존 40칸 → 스페어 보관 여유 확보).
- **장비 잠금 (`RequestToggleLockItem(uid)`)**: `item.locked = true/false`. 잠금된 장비와 장착 중인 장비, `pendingPotential` 대기 중인 장비는 판매/분해/일괄정리 불가.
- **개별 판매 (`RequestSellEquip(uid)`)**: `reqLevel * 150` 메소 지급 후 인벤토리 삭제.
- **개별 분해 (`RequestDismantleEquip(uid)`)**: `math.max(10, math.floor(reqLevel * 0.4))` 주문의 흔적 환급 (+ 에픽 이상 잠재 장비 분해 시 수상한 큐브 1~2개 보너스).
- **일괄 분해 (`RequestBulkDismantle(maxReqLevel)`)**: 미장착 · 미잠금 · 비파괴 · `star == 0` · `potentialGrade == "Rare"` · `reqLevel <= maxReqLevel` 조건을 만족하는 하위 장비만 안전하게 일괄 분해하여 주문의 흔적 환급.
- **완료 조건 (AC)**:
  - [ ] 착용 레벨 미달 장비는 장착이 차단된다.
  - [ ] 펜살리르/카루타/앱솔/아케인 장착 개수에 따라 세트 보너스가 전투력/스탯창에 실시간 반영된다.
  - [ ] 잠금 장비·장착 장비·강화(1성 이상 또는 에픽 이상) 장비는 일괄 분해에서 절대 삭제되지 않는다.

## F8. 오프라인 방치 보상 (최대 12시간) `[신규 구현]`

### F8.1 타임스탬프 & 계산 규칙
- **저장 시점**: `SaveProfileAsync` 및 `HandleUserLeaveEvent`에서 `profile.lastSaveUtcMs = DateTime.UtcNow.Elapsed` (UTC 밀리초)와 `profile.lastHuntingMapName`을 갱신.
  - *(마을에서 종료했더라도 직전에 사냥하던 `lastHuntingMapName`을 유지하여 오프라인 보상이 증발하지 않도록 설계. 한 번도 사냥터에 안 갔다면 `HenesysHunt1` 기본값 적용.)*
- **재접속 정산 (`LoadProfileForUser`)**:
  - `elapsedSec = math.floor((nowUtcMs - profile.lastSaveUtcMs) / 1000)`
  - `elapsedSec < 60`이면 정산 팝업 미표시.
  - `cappedSec = math.min(elapsedSec, 12 * 3600)` (최대 12시간).
  - **분당 기대 처치 수(`killsPerMin`)**: 기본 `18마리/분` × 전직 티어 보정(`1 + jobTier * 0.15`), 단 스타포스 미달 맵이면 `× 0.65`.
  - **오프라인 효율**: **`80%` (`0.80`)**.
  - 산출 보상:
    - `gainExp = floor(mapInfo.mobExp * killsPerMin * (cappedSec / 60) * 0.80 * (1 + expPct/100))`
    - `gainMeso = floor(mapInfo.mobMeso * killsPerMin * (cappedSec / 60) * 0.80 * (1 + mesoPct/100))`
    - `gainTrace = floor(mapInfo.mobTrace * 0.42 * killsPerMin * (cappedSec / 60) * 0.80 * (1 + dropPct/100))`
    - `gainSuspiciousCube = floor(0.06 * killsPerMin * (cappedSec / 60) * 0.80)`
- **수령 플로우**:
  - 재접속 시 `profile.pendingOfflineReward`에 계산 결과를 저장하고 클라이언트에 정산 팝업을 표시.
  - 유저가 **`[보상 수령]`** 버튼 클릭 → `RequestClaimOfflineReward()` 호출 시 실제 경험치(레벨업 포함)/메소/주흔/큐브 지급 후 `pendingOfflineReward = nil` & 즉시 저장.
- **완료 조건 (AC)**:
  - [ ] 60초 미만 재접속 시 팝업이 뜨지 않는다.
  - [ ] 12시간 초과 방치 시 정확히 12시간(43,200초)으로 상한 캡이 적용된다.
  - [ ] 수령 버튼을 두 번 눌러도 중복 지급되지 않는다(서버에서 `pendingOfflineReward` 즉시 소거).

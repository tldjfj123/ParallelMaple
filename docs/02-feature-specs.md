# ParallelMaple 기능별 상세 명세서 (v2.0)

> 모든 기능은 **AI 에이전트가 추가 질문 없이 바로 구현·검증할 수 있는 수준**으로 유저 플로우, 상세 규칙/공식, 예외 처리, 완료 조건(AC)을 정의합니다.  
> 상태 태그: `[As-Is 완료]` / `[수정 필요]` / `[신규 구현]`

## F1. 전투 · 자동사냥 · 자동포션 · 사망 규칙

### F1.1 자동사냥 & 수동 병행 `[As-Is 완료]`
- **토글**: `F` 키 또는 HUD 버튼으로 ON/OFF.
- **타겟 탐색**: 현재 맵에서 살아있는 몬스터 중 같은 발판(`|dy| <= 1.35`) 우선, 없으면 `|dx| + |dy| * 2.5` 최소 대상 추적.
- **스킬 연계**: 현재 전직 티어 기준 해금된 최고 효율 광역기/주력기 자동 시전 (`AutoHuntComponent:PickBestAutoSkillId`).
- **수동 개입**: 방향키/점프/스킬키 입력 시 즉시 `ManualPauseUntil = now + 2.0초` (스킬키는 `1.2초`) 유예 후 자동 복귀.
- **자석펫 (`P` 토글)**: 기본 ON. 3펫(루나/퍼피/키티)이 착지 후 `0.55초` 지난 바닥 드랍을 광역(`9.5m × 5.2m`)으로 자동 흡입.

### F1.2 공용 사냥터 타격 기여 보상 `[As-Is 완료]`
- 몬스터 피격 시 `Monster.HitContributors[userId] = true` 기록.
- 몬스터 사망 시 `0.15초` 후 기여자 전원에게 **개인별 독립 경험치 + 개인 바닥 드랍** 지급.

### F1.3 자동 포션 & 피격/사망 처리 `[신규 구현 / 수정 필요]`
- **기존 임시 로직 제거**: `PlayerDataLogic:RecalculateStats` 내부의 `Hp < MaxHp * 0.65` 시 강제 풀회복 코드를 제거합니다.
- **자동 포션 규칙 (서버 권위, `PlayerDataLogic` 또는 `SurvivalLogic`)**:
  - 플레이어가 피격되어 `Hp > 0`이고 `Hp / MaxHp <= profile.autoPotionThreshold` (기본값 `0.50`, 추후 설정 가능)일 때 서버가 자동 포션 발동.
  - 내부 쿨타임: `1.0초` (연속 피격 시 포션 증발 방지).
  - 포션 선택 우선순위: 보유 중인 포션 중 **레벨 구간에 맞는 기본 포션 우선** (`red_potion` → `white_potion` → `blue_potion` → `power_elixir`, 단 `Hp/MaxHp <= 0.25` 위급 시 `power_elixir` 우선 사용).
  - 보유 포션이 0개이면 클라이언트 토스트 `"⚠️ 보유한 포션이 없습니다! 마을 상점에서 보충하세요."` (30초 쿨타임 알림).
- **사망 처리**:
  - **일반 사냥터**: `Hp <= 0` 도달 시 경험치/메소 패널티 **없음**. `2.0초` 후 `Hp = MaxHp`로 회복하여 마을(`TileMapTemplate`)로 이동 + 클라이언트 자동사냥 OFF + 토스트 `"체력이 0이 되어 헤네시스로 귀환했습니다."`.
  - **보스전 인스턴스**: F6 보스전 데스카운트 규칙 따름.
- **완료 조건 (AC)**:
  - [ ] 피격으로 HP가 50% 이하가 되면 서버에서 포션 1개가 자동 차감되고 HP가 회복되며 클라이언트에 동기화된다.
  - [ ] 포션이 모두 소진되어 HP가 0이 되면 일반 사냥터에서는 경험치 손실 없이 헤네시스로 부활한다.

### F2.2 데미지 & 전투력 공식
- **기본 데미지**: `base = ((totalMainStat * 4) * totalAtt) / 135.0`
- **배율**: `dmgMult = (1 + dmgPct/100) * (1 + finalDmgPct/100)`
- **스타포스 필드 보정(`sfMult`)**: 스타포스 요구 맵에서 충족 시 `1.25`, 미달 시 `0.72`
- **보스 대상 추가 보정 (`[신규 구현]`)**:
  - `defender`가 보스 몬스터일 경우:
    - 보스 데미지 합산: `dmgMult = (1 + (dmgPct + bossDmgPct)/100) * (1 + finalDmgPct/100)`
    - 방어율 무시(방무) 공식: `effectiveDef = bossPdr * (1 - iedPct / 100)`, `iedMult = max(0.05, 1 - effectiveDef / 100)`
- **콤보 어택**: 2차 이상 적중 시 1스택 증가(최대 5/7/10), 스택당 `최종 데미지 +6%`, `추가 경험치 +1%`.
- **레벨업**: 최대 Lv.200, KMS 1배 경험치 테이블. 레벨업 시 HP 완전 회복 + 빛기둥 이펙트 + 반경 `4.6m × 2.6m` 내 일반 몬스터 최대 8마리 즉사 충격파.

## F3. 사냥터 18개 & 스타포스 지역 `[As-Is 완료 / 드랍풀 수정 필요]`

### F3.1 입장 & 텔레포트 규칙
- 마을(`TileMapTemplate`)은 언제든 이동 가능.
- 사냥터 18개(`HenesysHunt1` + `Hunt01`~`Hunt17`)는 `profile.level >= mapInfo.reqLevel` 충족 시 이동 가능 (`M` 창).
- **스타포스 사냥터 4곳** (`Hunt10` 30★ / `Hunt11` 55★ / `Hunt12` 80★ / `Hunt14` 140★):
  - 스타포스 미달이어도 입장은 허용하되 경고 표시 + 데미지 `0.72배` 패널티.
  - 충족 시 데미지 `1.25배` + 추가 경험치 `+15%`.

### F3.2 사냥터 장비 드랍풀 개편 `[수정 필요]`
- **원칙**: 일반 사냥터에서는 **최대 Lv.140 펜살리르 세트까지만** 드랍한다. 카루타(150)/앱솔랩스(160)/아케인셰이드(200)는 일반 사냥터 드랍풀에서 **완전 제거**하고 F6 보스전 & 보스 코인 상점 전용으로 이전한다.
- 구간별 드랍풀은 [docs/03-data-reference.md](docs/03-data-reference.md) 섹션 5 참조.
- **완료 조건 (AC)**:
  - [ ] Lv.160~200 사냥터에서 카루타/앱솔/아케인 장비가 드랍되지 않고, 펜살리르 스페어 및 고효율 메소/주흔/큐브/전리품이 드랍된다.

## F4. 장비 · 정통 점진 성장 · 세트 효과 · 인벤토리 정리 `[수정 필요 / 신규 구현]`

### F4.1 신규 유저 초기 지급 개편 `[수정 필요]`
- 기존 테스트용 초기 지급(`Lv.140 펜살리르 풀세트 + 50만 메소 + 주흔 5,000 + 큐브 65개`)을 **정통 점진 성장용 스타터**로 변경합니다:
  - 레벨: `Lv.1`, `jobTier = 0` (초보자)
  - 초기 장비: `Lv.1 초보자 한손검(wooden_sword)` + `Lv.1 초보자 모자/상의/장갑/신발` 5부위 장착 *(보조무기/엠블렘/반지는 사냥/전직/보스로 순차 해금 및 장착)*
  - 초기 재화: `meso = 5,000`, `spellTrace = 50`, `cubes = { suspicious = 3 }`, `potions = { red_potion = 20 }`
  - 기존 테스트 계정이 저장되어 있는 경우를 고려해 스키마 `version = 3`으로 올리되 기존 유저 장비는 강제 삭제하지 않고 유지합니다.

### F4.2 착용 레벨 제한 강제 `[신규 구현]`
- `RequestEquipItem(uid)`에서 `profile.level < item.reqLevel`이면 장착 거부 + 토스트 `"🔒 Lv.<reqLevel>부터 장착할 수 있는 장비입니다!"`.

### F4.3 장비 세트 효과 (2 / 4 / 6세트) `[신규 구현]`
- 장비 마스터에 `setId` 필드를 추가 (`"pensalir"`, `"karuta"`, `"absolab"`, `"arcane"`).
- `RecalculateStats`에서 현재 장착 중이고 파괴되지 않은(`not isDestroyed`) 장비들의 `setId`별 개수를 집계하여 아래 세트 보너스를 합산합니다:

| 세트 (`setId`) | 2세트 | 3세트 | 4세트 | 5세트 (핵심 8부위 풀세트) |
| :--- | :--- | :--- | :--- | :--- |
| **펜살리르** (`pensalir`: 무기/모자/상의/장갑/신발) | STR +10, MaxHP +300 | 공격력 +8 | 방무 +15%, 데미지 +5% | 공격력 +15, STR +20, 일반/전체 데미지 +8% |
| **카루타** (`karuta`: 무기/모자/상의) | STR +20, 공격력 +15 | **공격력 +40, 보스 데미지 +30%** | - | - |
| **앱솔랩스** (`absolab`: 무기/모자/상의/장갑/신발) | STR +25, 공격력 +20 | 공격력 +30, 보공 +10% | 공격력 +35, 방무 +10% | **공격력 +50, 보스 데미지 +20%** |
| **아케인셰이드** (`arcane`: 무기/모자/상의/장갑/신발) | STR +40, 공격력 +35 | 공격력 +45, 보공 +15% | 공격력 +55, 방무 +10% | **공격력 +80, 보스 데미지 +30%** |

> *(핵심 8부위 기준으로 원작의 인기 조합인 **카루타 3세트 + 앱솔 2세트(장갑/신발)** 또는 **앱솔 5세트 / 아케인 5세트** 선택지가 자연스럽게 성립하도록 2~5세트 단계 설계)*

### F4.4 인벤토리 잠금 / 판매 / 분해 `[신규 구현]`
- **인벤토리 최대 칸수**: 장비 60칸으로 확장 (기존 40칸 → 스페어 보관 여유 확보).
- **장비 잠금 (`RequestToggleLockItem(uid)`)**: `item.locked = true/false`. 잠금된 장비와 장착 중인 장비, `pendingPotential` 대기 중인 장비는 판매/분해/일괄정리 불가.
- **개별 판매 (`RequestSellEquip(uid)`)**: `reqLevel * 150` 메소 지급 후 인벤토리 삭제.
- **개별 분해 (`RequestDismantleEquip(uid)`)**: `math.max(10, math.floor(reqLevel * 0.4))` 주문의 흔적 환급 (+ 에픽 이상 잠재 장비 분해 시 수상한 큐브 1~2개 보너스).
- **일괄 분해 (`RequestBulkDismantle(maxReqLevel)`)**: 미장착 · 미잠금 · 비파괴 · `star == 0` · `potentialGrade == "Rare"` · `reqLevel <= maxReqLevel` 조건을 만족하는 하위 장비만 안전하게 일괄 분해하여 주문의 흔적 환급.
- **완료 조건 (AC)**:
  - [ ] 착용 레벨 미달 장비는 장착이 차단된다.
  - [ ] 펜살리르/카루타/앱솔/아케인 장착 개수에 따라 세트 보너스가 전투력/스탯창에 실시간 반영된다.
  - [ ] 잠금 장비·장착 장비·강화(1성 이상 또는 에픽 이상) 장비는 일괄 분해에서 절대 삭제되지 않는다.

## F5. 3대 강화 시스템 `[As-Is 완료 — 수치 확정]`

> 모든 판정/차감/저장은 `@ExecSpace("Server")` (`EnhanceLogic`)에서 처리합니다.

### F5.1 주문서 (주문의 흔적)
- **확정 비용 (현재 코드 기준 쾌적 밸런스)**:
  - `100% 작`: 15 주흔 (무기 공+3/주+1, 방어구 주+3)
  - `70% 작`: 30 주흔 (무기 공+5/주+2, 방어구 주+5)
  - `30% 작`: 60 주흔 (무기 공+7/주+3, 방어구 주+7/공+1)
  - `15% 작`: 100 주흔 (무기 공+9/주+4, 방어구 주+10/공+2)
  - `순백의 주문서 10%`: 250 주흔 (`scrollFail > 0`일 때 업횟 +1 복구)
  - `이노센트 주문서 50%`: 500 주흔 (주문서/황망/스타포스 초기화, 잠재능력 유지)
  - `황금 망치 100%`: 300 주흔 (장비당 1회 업횟 +1)
- **연속 강화**: 1회 요청으로 남은 업횟 또는 주흔 소진까지 일괄 처리 후 요약 반환.

### F5.2 스타포스 (KMS 0~25성)
- **해금 조건**: `upgradeRemaining == 0`, `canStarforce == true`, `isDestroyed == false`.
- **최대 성수**: `~109`: 8★ / `110~119`: 10★ / `120~129`: 15★ / `130~139`: 20★ / `140+`: 25★.
- **확률**: 0~14성 파괴 없음, 15성부터 파괴 시작 (15성·20성 하락 방지).
- **파괴 방지**: 15→16성, 16→17성에서 토글 시 메소 ×2, 파괴 확률 0%.
- **찬스 타임**: 2연속 하락 시 다음 1회 성공률 100% (파괴 0%).
- **스타캐치**: **간편 토글 방식 확정** (토글 ON 시 성공률 ×1.05, 미니게임 없음).
- **파괴 & 스페어 복구**: 파괴 시 `isDestroyed = true, star = 0`("장비의 흔적", 주문서·잠재·천장 유지, 자동 장착 해제) → 인벤토리의 미장착·미잠금·비파괴 동일 `itemId` 스페어 1개 소모하여 **12성으로 즉시 복구**.

### F5.3 잠재능력 & 큐브
- 4등급 (`Rare` / `Epic` / `Unique` / `Legendary`), 획득 시 기본 Rare 3줄.
- 2번째 줄 이탈 10%, 3번째 줄 이탈 5%.
- 큐브 5종 (`수상한 / 장인의 / 명장의 / 레드 / 블랙`), 장비별 현재 등급 등업 천장(`cubePityCount`).
- 블랙 큐브는 `pendingPotential`에 저장 → 유저가 `[BEFORE 유지]` 또는 `[AFTER 적용]` 확정 전까지 해당 장비 재큐브/분해 차단.

## F6. 1인 인스턴스 보스전 5단계 & 보스 코인 상점 `[신규 구현]`

### F6.1 보스 라인업 & 공통 규칙
- **인스턴스 방식**: **1인 개인 인스턴스** (`RoomService` 또는 1인 전용 보스 맵 인스턴스 — 구현 방식은 [docs/05-architecture.md](docs/05-architecture.md) 확정).

  - 제한 시간: **10분 (600초)**
  - 데스카운트: **5회** (사망 시 1 차감, 2초 후 보스 맵 스폰 위치에서 HP 100% + 3초 무적 부활; 0회 도달 시 실패 퇴장)

### F6.2 보스 패턴 설계 (MVP → 확장)
- 각 보스는 최소 **2~3개의 시그니처 패턴**을 가집니다 (바닥 경고 텔레그래프 `1.2초` → 공격 판정):
  - **자쿰**: 팔 내려찍기(바닥 경고 존, 최대 HP 30% 피해) + 낙석
  - **혼테일**: 브레스(전방 범위, 최대 HP 35% 피해) + 꼬리 내려치기
  - **벨룸**: 땅속 잠복 후 돌출(바닥 경고, 최대 HP 50% 피해) + 낙석 스턴
  - **스우**: 낙하물 + 레이저/밀격(최대 HP 45% 피해)
  - **루시드**: 초승달 검기 투사체 + 폭탄 경고(최대 HP 55% 피해)
- 보스 공격은 `MaxHp` 비율 피해를 포함하여 스펙이 높아도 포션/회피의 재미를 유지합니다.

### F6.3 보스 코인 상점 교환표
- 각 보스 코인은 `profile.bossCoins[coinId]`에 저장.
- **교환 비용 (확정 가이드)**:
  - 실버블라썸 링: 하급 코인 `15개` / 고귀한 이피아의 반지·데이모스 실드: 중급 코인 `25개`
  - 카루타 방어구(모자/상의): 루타비스 코인 `30개` / 파프니르 무기: `50개`
  - 앱솔랩스 방어구: 앱솔랩스 코인 `40개` / 앱솔랩스 무기: `60개`
  - 아케인셰이드 방어구: 아케인 코인 `50개` / 아케인셰이드 무기: `80개`
  - *(모든 보스 장비는 파괴 복구 스페어 용도로 무제한 반복 교환 가능)*

### F6.4 완료 조건 (AC)
- [ ] 레벨 미달 또는 일일 클리어 횟수 소진 시 보스 입장이 차단된다.
- [ ] 보스 클리어 시에만 일일 횟수가 차감되고, 코인/메소/큐브/장비 보상이 지급되며 클리어 결과 팝업 후 마을로 귀환한다.
- [ ] 제한시간 10분 초과 또는 데스카운트 5회 소진 시 실패 팝업 후 횟수 차감 없이 마을로 귀환한다.
- [ ] KST 00:00 이후 재접속/재시도 시 일일 횟수가 자동 초기화된다.

## F8. 오프라인 방치 보상 (최대 12시간) `[신규 구현]`

### F8.1 타임스탬프 & 계산 규칙
- **저장 시점**: `SaveProfileAsync` 및 `HandleUserLeaveEvent`에서 `profile.lastSaveUtcMs = DateTime.UtcNow.Elapsed` (UTC 밀리초)와 `profile.lastHuntingMapName`을 갱신.
  - *(마을에서 종료했더라도 직전에 사냥하던 `lastHuntingMapName`을 유지하여 오프라인 보상이 증발하지 않도록 설계. 한 번도 사냥터에 안 갔다면 `HenesysHunt1` 기본값 적용.)*
- **재접속 정산 (`LoadProfileForUser`)**:
  - `elapsedSec = math.floor((nowUtcMs - profile.lastSaveUtcMs) / 1000)`
  - `elapsedSec < 60`이면 정산 팝업 미표시.
  - `cappedSec = math.min(elapsedSec, 12 * 3600)` (최대 12시간).
  - **분당 기대 처치 수(`killsPerMin`)**: 기본 `18마리/분` × 전직 티어 보정(`1 + jobTier * 0.15`), 단 스타포스 미달 맵이면 `× 0.65`.
  - **오프라인 효율**: **`80%` (`0.80`)**.
  - 산출 보상:
    - `gainExp = floor(mapInfo.mobExp * killsPerMin * (cappedSec / 60) * 0.80 * (1 + expPct/100))`
    - `gainMeso = floor(mapInfo.mobMeso * killsPerMin * (cappedSec / 60) * 0.80 * (1 + mesoPct/100))`
    - `gainTrace = floor(mapInfo.mobTrace * 0.42 * killsPerMin * (cappedSec / 60) * 0.80 * (1 + dropPct/100))`
    - `gainSuspiciousCube = floor(0.06 * killsPerMin * (cappedSec / 60) * 0.80)`
- **수령 플로우**:
  - 재접속 시 `profile.pendingOfflineReward`에 계산 결과를 저장하고 클라이언트에 정산 팝업을 표시.
  - 유저가 **`[보상 수령]`** 버튼 클릭 → `RequestClaimOfflineReward()` 호출 시 실제 경험치(레벨업 포함)/메소/주흔/큐브 지급 후 `pendingOfflineReward = nil` & 즉시 저장.
- **완료 조건 (AC)**:
  - [ ] 60초 미만 재접속 시 팝업이 뜨지 않는다.
  - [ ] 12시간 초과 방치 시 정확히 12시간(43,200초)으로 상한 캡이 적용된다.
  - [ ] 수령 버튼을 두 번 눌러도 중복 지급되지 않는다(서버에서 `pendingOfflineReward` 즉시 소거).
  - [ ] 서버가 재시작된 뒤 접속해도 `DateTime.UtcNow` 기반으로 오프라인 시간이 정확히 계산된다.

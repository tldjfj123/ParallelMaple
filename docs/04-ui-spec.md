# ParallelMaple UI 화면별 상세 명세서 (v2.1 — 빅뱅 HUD × 빅뱅 이후·현대 시스템 창)

> **디자인 원칙 (옵션 A 확정 — 하이브리드 공식 에셋 조합):**
> - **메인 인게임 하단 HUD**: 2010 빅뱅 향수를 살린 공식 **`StatusBar2` + `QuickSlot`** 유지
> - **팝업 / 시스템 창 전체 (24슬롯 장비·인벤·스탯·스킬·상점·보스·오프라인)**: 빅뱅 이후~현대 메이플 공식 **`UIWindow4`** 프레임 적용
> - **전용 특수 창**: 강화창은 **`StarForce` / `Enchant` / `Cube`**, 사냥터 길라잡이는 **`MapleGuide`** 공식 스프라이트 적용
> - 모든 UI 에셋은 `msw-mcp` (`source: "maplestory"`) 공식 리소스에서 조회·검증된 RUID만 사용합니다.

## 2. 화면별 명세 (기존 6화면 + 신규 3화면)

### 화면 1. 메인 인게임 HUD (`IdleHUDGroup.ui`) `[As-Is 완료 / 버튼 추가]`
- **하단 상태바 (`StatusBar2`)**:
  - 좌측: 노란 굵은 `Lv.숫자` + 직업명(초보자/검사/파이터/크루세이더/히어로) + 전투력
  - 중앙: 빨간 HP 바 / 파란 MP 바 / 하단 노랑-연두 EXP 바
  - 메뉴 버튼 열: `E` 장비 · `I` 인벤 · `S` 스탯 · `K` 스킬 · `U` 강화 · `M` 사냥터 · **`T` 보스** · **`B` 상점** · `F` 자동 · `P` 펫
  - *(보스전 입장 중에는 상단 중앙에 전용 **보스 HP 바 + 남은 시간(10:00) + 데스카운트(♥×5)** 오버레이 표시)*
- **우측 하단 퀵슬롯 (`QuickSlot`)**: 정사각형 아이콘 칸 + 좌상단 노란 키캡(`1`~`5`, `F`, `P`) + 쿨타임 오버레이.
- **우측 획득 로그**: 경험치/추가경험치/메소/아이템/장비 획득 실시간 스크롤 로그.

### 화면 2. 장비창 (`E`) `[수정 필요 — 현대 메이플 24슬롯 · UIWindow4 개편]`
- 빅뱅 이후~현대 공식 **`UIWindow4`** 장비창 프레임 적용.
- **현대 메이플 정식 24부위 슬롯 격자 배치** (원작 장비창 5열 그리드 고증):
  - 무기/특수: `Weapon`, `SubWeapon`, `Emblem`
  - 방어구: `Hat`, `Top`, `Pants`, `Shoes`, `Gloves`, `Cape`, `Shoulder`
  - 장신구: `Ring1`~`Ring4`, `Pendant1`~`Pendant2`, `Face`, `Eye`, `Earring`, `Belt`
  - 특수: `Pocket`, `Badge`, `Medal`, `AndroidHeart`
- 슬롯별 잠재 등급 테두리(레어 파랑 / 에픽 보라 / 유니크 노랑 / 레전드리 초록) + `★성수` 배지.
- 한벌옷 장착 시 `Pants` 슬롯은 반투명 비활성 표시.
- **[신규 추가 — T1.2]**: 하단 요약 영역에 **활성화된 세트 효과 배지** 표시 (예: `카루타 3/4 · 앱솔랩스 5/7 · 보스장신구 5/7`).

### 화면 3. 인벤토리창 (`I`) `[As-Is 완료 / 잠금·판매·분해 UI 추가]`
- 3탭 구조: `[장비 (현재/60)]` / `[소비 (포션·큐브)]` / `[기타 (주흔·전리품·보스코인)]`.
- **[신규 추가 — T1.3]**:
  - 선택된 장비 액션 영역에 **`[장착]`**, **`[강화]`**, **`[잠금 🔒/해제]`**, **`[판매 (메소)]`**, **`[분해 (주흔)]`** 버튼 배치.
  - 상단 또는 하단에 **`[하위 장비 일괄 분해]`** 버튼 + 확인 모달(분해 예정 개수 & 획득 주흔 미리보기).
  - 잠금 장비는 좌상단 🔒 아이콘, 파괴 흔적 장비는 붉은 반투명 테두리 표시.
  - 착용 레벨 미달 장비는 레벨 텍스트를 붉은색(`Lv.140 필요`)으로 표시.

### 화면 4. 스탯창 (`S`) & 스킬창 (`K`) `[수정 필요 — 수동 AP 배분 UI 추가]`
- **스탯창 (`S`)**:
  - 캐릭터명, 전직, 레벨, 전투력, 총 스타포스(`★`)
  - **[신규 — T1.1] 수동 AP 배분 영역**: 남은 `ABILITY POINT (AP)` 표시 + **`STR` / `DEX` / `INT` / `LUK`** 각각의 `[+]` 버튼 + **`[자동 배분]`** 버튼
  - 세부 스탯: 공격력, 최종뎀, 보공, 방무, 크확/크뎀, 메획/드랍/추경, 콤보 스택 + 활성 세트 효과 목록 + 자동 포션 ON/OFF 및 발동 임계치(`50%`) 표시.
- **스킬창 (`K`)**: 1~4차 탭 전환, 스킬 아이콘/설명/배율/타수/쿨타임 + 전직 가능 시 상단 강조 `[전직하기 (J)]` 버튼.

### 화면 5. 사냥터 길라잡이창 (`M`) & 사냥터 상단 진행 HUD `[수정 필요 — 18챕터 × 5스테이지]`
- **길라잡이창 (`M`)**: 18개 챕터(`Ch.1`~`Ch.18`) 목록, 각 챕터의 해금 상태·현재 최고 스테이지(`1~5`)·스타포스 요구치(`★30/55/80/140`)·**로테이션 버닝 배지(`🔥 버닝 1~10단계`)**·특화 태그 표시 + 원하는 스테이지 원클릭 주차 이동 + 상단 `[헤네시스 귀환]`.
- **사냥터 상단 미니 진행바 (1인 사냥터 체류 시)**:
  - 현재 위치 (`Ch.13-3 커닝타워`) + 스테이지 처치 게이지(`1,840/3,000`) + 달성 시 강조 **`[다음 단계 / 챕터 보스 도전!]`** 버튼
  - 우측: **사냥 도파민 상자 게이지 (`74%`, 충전 시 반짝임 → 클릭하면 3택 1 보상 카드 팝업!)** + 활성 룬 버프 타이머(`경험치 2배 02:41`).

### 화면 6. 장비 강화 & 큐브창 (`U` / `C`, `EnhanceUIGroup.ui`) `[As-Is 완료]`
- 좌측: 장착 24부위 + 인벤토리 목록 (잠금/흔적 상태 표시).
- 우측 상단: 장비 상세 툴팁 (이름, `+업횟`, `★성수`, 잠재 3줄, 스탯).
- 우측 하단 3탭:
  1. `[주문서]`: 100/70/30/15%, 순백/이노/황망, `[1회]` / `[연속작]`
  2. `[스타포스]`: 확률·비용·스탯 미리보기, 파괴방지 체크, 스타캐치 토글, 찬스타임 배너, 파괴 시 `[스페어 12성 복구]`
  3. `[큐브]`: 큐브 5종 보유량, 천장 게이지(`N / Max`), 블랙 큐브 시 `BEFORE` vs `AFTER` 비교 선택 버튼.

### 화면 7. NPC 상점창 (`B`, 신규 `ShopUIGroup.ui`) `[신규 — T1.4]`
- 별도 `.ui` 파일(`ShopUIGroup.ui`)로 분리하여 충돌 방지.
- 상단 3탭:
  1. **`[잡화/강화 상점]`**: 포션 4종(×10), 주흔(×100), 수상/레드/블랙 큐브, **AP 초기화 주문서**, **보조무기(Lv.30/60/100) · 엠블렘(Lv.60/100)** + 현재 메소 표시 + `[구매]` 버튼.
  2. **`[펫 상점]`**: 2번 펫(50만), 3번 펫(200만), **자석펫 업그레이드(1,000만)** 보유 상태 및 `[구매]` 버튼.
  3. **`[보스 코인 상점]`**: 5종 보스 코인 보유 현황 바 + 교환 가능 보스 장비(보스 장신구 9셋, 카루타/앱솔/아케인 전 부위) + 필요 코인 + `[교환]` 버튼.

### 화면 8. 1인 보스전 입장창 (`T`) & 보스 HUD (신규 `BossUIGroup.ui`) `[신규 — T3.4]`
- **보스 선택 팝업 (`T`)**:
  - 5단계 보스 카드 리스트 (`자쿰` / `혼테일` / `카루타` / `스우` / `루시드`).
  - 각 카드: 요구 레벨, 권장 전투력, 남은 일일 클리어 횟수(`1/1` 등), 주요 드랍/코인 미리보기, `[입장하기]` 버튼.
- **보스전 전용 HUD (보스 맵 체류 시 자동 표시)**:
  - 상단 중앙: 보스 이름 + 대형 붉은 HP 바 (`현재 HP / 최대 HP (%)`) + 남은 시간 (`09:42`) + 남은 데스카운트 (`♥ ♥ ♥ ♥ ♥`) + `[포기/퇴장]` 버튼.
- **결과 팝업**: 클리어(소요 시간 + 획득 코인/메소/큐브/장비 목록 + `[마을 귀환]`) / 실패(사유: 데스카운트 소진 또는 시간 초과 + `일일 횟수 미차감 안내` + `[마을 귀환]`).

### 화면 9. 오프라인 방치 정산 팝업 (신규 `OfflinePopupGroup.ui`) `[신규 — T2.2]`
- 60초 이상 오프라인 후 재접속 시 중앙 모달로 자동 표시.
- 표시 항목: 경과 시간(`예: 5시간 24분 / 최대 12시간`), 정산 기준 사냥터명, 예상 처치 수, 획득 예정 **경험치 / 메소 / 주문의 흔적 / 수상한 큐브**.
- 하단 대형 **`[보상 수령하기]`** 버튼 (클릭 시 `RequestClaimOfflineReward` 호출 후 팝업 닫힘).
